## Website image assets

Prefer WebP for website photographs and raster backgrounds. Use lossless WebP for text, logos and transparent artwork when it is smaller, preserving alpha and sharp edges. Keep SVG artwork as vector. Before switching references, verify image dimensions, visual quality and file-size savings; do not upscale or recompress an already efficient asset unnecessarily. Retain original masters and archive/download links when adding optimized website versions.
